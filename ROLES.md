# Roles → Skills + Tools Matrix

**Spawn convention.** Everything goes through the `Agent` tool — there is no `TeamCreate` step, and `team_name` is deprecated and ignored. Persistent roles (Coder, Reviewer, Tester, Backend-Tester) are spawned **with** `name`, which is what makes them addressable via `SendMessage`; address them by the name the spawn *returned* (`coder` can come back as `coder-2`), and end each brief with "SendMessage to `main` when done" or they report nothing. Ephemeral specialists are spawned **without** `name`, and their report arrives on its own as a task-notification. There is no dismiss call — teammates idle out on their own. See `skills/team-handoff/SKILL.md` for the spawn / message / `plan_create()` primitives.
